## 窗口与布局

- 图片附件按钮改用真正的 flex/grid 居中；SVG 为块元素，不再受文字基线影响。空图片列表与错误占位不再制造额外空白。
- 仅设置 WebView 透明背景不足以去掉 WinForms 宿主矩形。球的宿主窗口增加原生椭圆裁剪；面板和菜单按卡片边界圆角裁剪，尺寸改变后重新应用。窗口透明区不再保留方形底板，但球本体仍保留浅/深主题底色。
- 菜单移除 `blur -> hide_menu`：Windows 转移焦点、球恢复显示或 WebView 初始化不再立即关闭菜单。重复右键是幂等显示；关闭、Esc 和选择动作仍可收起。透明页导航就绪后按实际打开意图恢复隐藏状态。

## 同步对话

- 两端监听同一个本机 `/workspace/events` SSE 通道，不依赖跨 WebView 的缓存或 localStorage 恰好共享。
- `start/frame/finish` 广播同一轮的会话、用户消息/图片、工具状态、回答、记忆引用与日程。`client_id` 只用于避免本端重复渲染，不充当认证。
- 断线后先接收当前在途轮次快照；结束后再读取已持久化历史校正。主界面有正在输入的草稿或正在查看其他已有对话时，不强行切换；侧栏仍出现新会话。
- 两端都可停止同一个在途轮次；取消仍走现有状态机回滚。事件缓存位于进程内，监听队列有界，不新增一份永久聊天数据库。
- 同步只传已有业务帧，不向界面暴露模型的内部推理内容。本轮不改成模型逐 token 流式调用；回答帧产生时会同步到两端。

## 思考程度与寒暄延迟

输入区提供「自动 / 快速 / 轻量思考 / 深入思考 / 充分思考」，下拉沿用统一控件并增加短切换动效，尊重减少动效偏好。小窗也提供同一选择，设置保存在本机；实际参数是每次请求独立传递，不改变共享模型对象。

- DeepSeek：快速传 `thinking.type=disabled`，其余档位启用思考并传 `low/high/max`。自动模式对精确识别的简单寒暄选择快速，其他请求默认轻量，不再默认高强度。
- OpenAI 推理模型：使用公共兼容档 `low/high`，不假定每个型号都支持 `none/max`。其他未适配模型继续使用供应商默认；没有用提示词假装底层支持不存在的档位。
- 简单寒暄不注入整份技能目录，不主动调用工具扫描工位；DeepSeek 寒暄请求明确禁止选工具。复杂任务的技能、沙箱与研究能力保留。
- DeepSeek 适配类保留 provider 专用的 `reasoning_content` 往返字段，满足多轮工具调用需要；该字段不显示给用户。随已有消息封装保存，重启后不会仅因丢失此字段而破坏后续调用。

参数依据已实际读取的 [DeepSeek 思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/) 与 [OpenAI 推理模型文档](https://developers.openai.com/api/docs/guides/reasoning?api-mode=chat)。未调用真实模型测量延迟，不承诺固定响应时长。

## MEMORY.md 与五层记忆

没有另建一套绕过治理的画像。`workspace/memory/MEMORY.md` 是原有治理条目的可编辑文本投影，记忆中心直接提供编辑器、范围、保存和重新加载。项目范围使用隔离的文件名，不能借范围字符串指定任意路径。

- 默认格式为 Markdown，每条记忆用空行分隔，可保留 `[偏好] / [项目] / [任务] / [经验]` 分类；不填写分类时作为项目知识处理。
- 发送前直接加入当前范围及 global 中的已确认有效内容，不再必须等词法查询命中、也不再固定只取五条。仍受召回开关、私密模式、范围和 token 预算控制；过大的内容可能不全部注入。
- 文本保存同步回原治理库：保留未改条目，新增/修改为显式确认，删除的条目停用；候选、拒绝、已删除、被替代和遗忘内容不自动混入。删除墓碑不放宽。
- 支持直接编辑本地文件；下一次读取/发送时在原治理锁下同步。文件和条目同时修改时保留双方，不自动覆盖：界面显示冲突，用户合并并显式保存后才替换当前范围内容。保存携带 revision，过期提交返回 409。
- 既有 Schema、衰减遗忘、检索、L4 注入、L5 候选沉淀与单条管理功能保留。文本只是更直观的编辑和默认上下文入口，不是“永久记录每一句聊天”的开关。

## 日程与弹窗

日程增加幂等 DELETE，删除时在现有 tasks 文件锁下同时移除条目与其提醒记录。取消提醒与真正删除分开；原完成、已读和编辑保留。

新增/编辑改为应用内模态表单：事项、日期、可选时间、提前分钟与创建时重复频率；不再使用浏览器 `prompt()` 连续询问。未填时间保存待办，不能声称已经安排定时提醒。保存失败在原表单内显示，保留输入。删除和取消使用同风格确认框，支持 Esc、取消、焦点定位、浅/深主题和窄屏。主卡片仍使用上一轮的内容比例布局。
