## 使用入口

1. **个人设置 → 从日常任务积累自己的方法 → 开启本地观察**，或在技能页开启。默认关闭；开启后只在本地观察，私密、不记录或关闭自动抽取时不参与。
2. **技能 → 待整理** 查看粗分组建议，选取来源并审阅有界预览。默认至少 3 个去重示例、至少 2 种输入；主题相似只是建议，不代表同一方法已经被学会。
3. 创建草稿后可手工编辑；需要模型整理时，单独填写本批次预算、现有兼容模型名称和已核对的人民币/百万 token 单价。读取页面、轮询和自动观察不会触发模型。
4. 保存、审阅，再明确选择启用。静态通过但无行为证据的标为**试用**；文本行为验证通过仅表示列出的文本约束通过，不代表工具执行、事实准确性或所有任务已验证。
5. **我的方法** 查看、改进、撤销或回退版本。小窗“对话选项”增加前往工作台审阅个人方法的入口。

## 实际实现

- `core/skill/learning/`：政策、共享 SQLite 事务、观察队列、候选/来源、串行作业及预算、发布与版本回退、按调用技能注入。
- `state_machine.py`：run 与 astream 在成功持久化后发送 best-effort 观察。观察失败不会撤销已提交轮次；失败/取消半轮不成为正文来源。长轮次始终保留原用户消息和有限回答尾部引用。
- 经验只存有限特征、引用和反馈；来源预览排除隐藏 reasoning，过滤常见凭据并参数化实例路径。没有把经验写成新的事实真值库，五层记忆保留。
- 新候选不注册 active 技能。审批绑定 revision/hash/基线；修改后旧行为证据失效。新文件先落盘，注册、切换版本与发布记录同事务；失败不改变旧 active，未引用的新正文可清理。
- 批准的个人技能继续用 SKILL.md 和现有目录/工具名称。load_skill 对个人方法只选择引用，正文在当前有效模型调用临时提供，不写入聊天历史；私密、scope、开关、文件 hash 与来源状态重新检查。
- 会话删除、记忆撤销/禁用/替换以及清理观察会使相关方法失效；队列迟到观察和作业结果不能复活旧来源。撤销文件只清理应用管理的版本目录，不删除普通技能或原始聊天。
- 预算在调用前预留、按完整 usage 结算；unknown/在途不清零，跨重启保留。取消后的晚到响应不会覆盖草稿；单一作业串行处理，无默认后台 LLM 或 fallback 试错调用。
- CLI 和桌面共用工作区、存储与选择策略，生命周期中关闭学习工作；跨进程只读核对作业 owner 存活，Windows 不用 os.kill 做探测。
- 前端增加同风格的来源选择、编辑审阅、作业状态、费用确认、试用标签和有限文本验证。旧技能开关与既有会话、记忆、日程功能保留。

## 范围与限制

- 当前模式发现是本地词/任务类别线索，不是全语义聚类。歧义交给示例审阅；当前没有接向量数据库或训练模型权重。
- 生成的是可读方法技能，不自动生成可执行插件，不自行修改内核；旧 EvolutionManager 的自动演化组件没有被悄悄设为默认运行。
- 行为评估首版为无工具的**文本约束对照**；UI 提供两个独立样例，API 最多五个。保留输入不直接重复训练来源，但小样本不证明统计显著或任意任务提升；没有把字符串检查冒充事实核验。
- 进程崩溃/队列满可丢少量未落库观察。已发出的供应商请求不能撤回，费用预留与未知状态继续保留；文件写入/服务不可用等错误有独立反馈。
- 前端没有进行人工鼠标点击和跨设备视觉验收；DOM 替身、JS 语法、API 和原生检查分别记账，不能互相冒充。
- 自动发现/手工审阅的功能离线验证完成；**真实模型是否能从个人样例提炼出有效方法，仍需用户明确新批次预算后验证**。未沿用任何旧额度。
- A1–A7 七项通用体验优化仍是另外的待办，没有借本轮交付宣称已全部完成。剩余依赖风险仍以原审计文档为准，本轮没有批量升级依赖。
